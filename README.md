# ProjectMind AI

AI-powered platform for final-year students to discover project ideas based on their skills and interests.

## Features
- Generate project ideas from skills and interests
- Recommend suitable technologies
- Suggest useful project features
- Create a development roadmap
- Suggest improvements and advanced features
